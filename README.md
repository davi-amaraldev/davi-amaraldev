## Featured Projects

### Node HTTP Users API

REST API built directly with Node.js native HTTP APIs without Express.

Built to understand what backend frameworks abstract away and how an HTTP application works from request to production deployment.

**Highlights**

* Native HTTP routing
* RESTful CRUD
* SQLite persistence
* Input validation
* Centralized error handling
* Unit and integration tests
* Docker
* Caddy reverse proxy
* HTTPS
* Oracle Cloud deployment

[View Repository](https://github.com/davi-amaraldev/node-http-users-api)
