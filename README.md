## Featured Projects

### Node HTTP Users API

REST API built from scratch using Node.js' native `node:http` module.

Focused on understanding the foundations behind web frameworks, including routing, HTTP methods, status codes, streams, validation, error handling, SQLite persistence and automated tests.

### DevFlow

Full-stack project focused on building a more realistic application architecture.

The backend is built with **Express, JavaScript and PostgreSQL**, exploring routes, controllers, services, middlewares, authentication and database integration.

The project also includes a web interface, connecting the front-end to the API and creating a complete end-to-end application.
